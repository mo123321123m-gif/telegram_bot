# Telegram Video Downloader Bot

## 🚀 Features
- Download from TikTok, YouTube, Instagram, Twitter, etc.
- Send back videos in high resolution, no watermark

## 🔧 Setup Steps

1. Create a bot using @BotFather and get your token.
2. Replace `YOUR_BOT_TOKEN_HERE` in `main.py` with your token.
3. Deploy this on [Render.com](https://render.com/):
   - Create a new Web Service.
   - Connect a repo or upload files.
   - Use **`worker: python main.py`** as the start command.
   - Choose Python as the environment and version 3.10+.
4. Enable persistent disk if needed.

Enjoy your bot! 🎉
